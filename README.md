# 🏫 7 «А» Сынып Порталы – ClassRoutine

Қазақстандағы мектеп сыныбына арналған заманауи, толыққанды цифрлық басқару және білім беру платформасы. Платформа 3 негізгі рөлге (**Мұғалім**, **Оқушы**, **Ата-ана**) бейімделген жеке мүмкіндіктермен жабдықталған.

---

## 🚀 Негізгі функциялар мен бөлімдер

### 1. 📅 1 апталық сабақ кестесі (`/schedule`)
- Дүйсенбіден сенбіге дейінгі апталық толық сабақ кестесі (уақыты, кабинеті, пән мұғалімі, қажетті оқу құралдары).
- Күндер бойынша және «Толық апта» форматында сүзгілеу.
- Мұғалім режимінде жаңа сабақ қосу, түзету және өшіру мүмкіндігі.
- Басып шығару (Print / PDF) функциясы.

### 2. 💬 Мұғалім мен Оқушы байланысы (`/communication`)
- **Жалпы сынып чаты:** Сыныптастар мен мұғалімдер арасындағы нақты уақыттағы диалог.
- **Пәндік сұрақ-жауап (Q&A):** Сабақ барысында түсінбеген есептер мен тақырыптар бойынша мұғалімге жеке сұрақ қою.
- **Үй тапсырмалары модулі:** Мұғалімнің тапсырма беруі, оқушының жауапты/файлды жүктеуі, мұғалімнің 1–10 балдық бағалауы және пікірі.

### 3. 🏆 Оқушылардың жетістіктері (`/achievements`)
- Пәндік олимпиадалар, ғылыми жобалар, спорт, өнер, үздік оқырман және үлгілі тәртіп марапаттары.
- **Мұғалімнің жеңіл марапаттау құралы:** Оқушыны таңдап, диплом/медаль түрін белгілеп, +XP ұпайларын беру (Конфетти анимациясымен).
- Сынып көшбасшыларының үздік үштік (Top 3) тұғыры және толық рейтингі.

### 4. 👨‍👩‍👦 Ата-ана мен Мұғалім байланысы (`/parent-portal`)
- Баланың оқу үлгерімі журналы (Формативті бағалар, 98% сабаққа қатысу көрсеткіші).
- Сынып жетекшісімен жеке құпия чат.
- **Мұғаліммен жеке кеңеске жазылу:** Ыңғайлы күн мен уақытты таңдап, кездесуге сұраныс жіберу.
- Ата-аналар жиналысы кестесі мен ресми хабарландырулар.

### 5. ⚡ «Көңілді үзіліс» сергіту жаттығулары (`/fun-break`)
- **👀 Көз жаттығулары («Қыран көз»):** Экранда қозғалатын нүктемен 1 минуттық интерактивті көз демалту анимациясы.
- **🧘 Сынып сергіту жаттығулары («Түзу тұлға»):** Омыртқа мен мойын бұлшықеттерін созуға арналған 30-60 секундтық таймерлі қадамдар.
- **🧠 Ми сергіту жұмбақтары:** Қазақша логикалық сұрақтар мен викториналар.
- **⚡ «Жылдам есептеу» сайысы:** 45 секундтық математикалық ойын.
- **⏱️ Үзіліс таймері:** Мектеп қоңырауының дыбысымен 5, 10, 15 минуттық кері санақ.

### 6. 🔐 Кіру / Тіркелу және Рөлдік басқару
- Header-дің оң жақ шетінде орналасқан «Кіру / Тіркелу» жүйесі.
- Google аккаунтымен бір рет басу арқылы кіру.
- 3 Рөл:
  1. 👨‍🎓 **Оқушы**
  2. 👩‍🏫 **Мұғалім**
  3. 👨‍👩‍👦 **Ата-ана**
- Тексеру және сынау үшін ыңғайлы рөлді жылдам ауыстыру батырмасы.

---

## 🛠️ Технологиялық стэк

- **Фреймворк:** Next.js 14 (App Router) + React 18
- **Тіл:** TypeScript
- **Стильдеу:** Tailwind CSS
- **Иконкалар:** Lucide React
- **Анимациялар мен эффекттер:** Canvas Confetti + Web Audio API Chime Synth
- **Деректер қоры және синхронизация:** Firebase & Firestore архитектурасы + LocalStorage реактивті сақтау
- **Орта:** VS Code / Next.js Sandbox
